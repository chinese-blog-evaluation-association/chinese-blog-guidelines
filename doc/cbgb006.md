# `CBGB006` - 内容与背景对比度过低

## 解释

站点大部分内容与背景的对比度应至少达到 AA 级。这是因为视力下降会导致许多人无法看清对比度较低的文字。为了让文字能被更多人看见，站点内容的最低对比度应达到此标准。

包括文字内容、自定义鼠标指针、图案等，都应考虑与背景的对比度。

相关解释：[理解最低对比度](https://www.w3.org/WAI/WCAG21/Understanding/contrast-minimum.html)。
