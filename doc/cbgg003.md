# `CBGG003` - 提供订阅源（Atom、RSS）应符合标准

## 解释

遵守 Atom 和 RSS 标准规范，确保订阅源的兼容性和可读性，便于各类阅读器正确解析。

标准文件：
- [Atom 1.0](https://www.rfc-editor.org/rfc/rfc4287)
- [RSS 1.0](https://validator.w3.org/feed/docs/rss1.html)
- [RSS 2.0](https://www.rssboard.org/rss-specification)

相关文档：
- [RSS 最佳实践](https://www.rssboard.org/rss-profile)
- [Atom 命名空间介绍](https://www.rssboard.org/rss-profile#namespace-elements-atom): `xmlns:atom="http://www.w3.org/2005/Atom"`
- [Content 命名空间介绍](https://www.rssboard.org/rss-profile#namespace-elements-content): `xmlns:content="http://purl.org/rss/1.0/modules/content/"`
- [Dublin Core 命名空间介绍](https://www.rssboard.org/rss-profile#namespace-elements-dublin): `xmlns:dc="http://purl.org/dc/elements/1.1/"`
- [Slash 命名空间介绍](https://www.rssboard.org/rss-profile#namespace-elements-slash): `xmlns:slash="http://purl.org/rss/1.0/modules/slash/"`

## 示例

可使用 W3C 提供的在线工具进行测试：[Feed Validation Service](https://validator.w3.org/feed/)。
